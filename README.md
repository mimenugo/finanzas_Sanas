=================================
FINANZAS SANAS - Portal Finanzas Sanas y Bienestar Financiero
Version 1.0
=================================

DESCRIPCIÓN:
Plataforma de administración financiera para consulta de pagos, calendarios, comprobantes y seguimiento de cuentas personales.
Perfecto para microfinancieras, cooperativas y prestamistas.

TECNOLOGÍAS:
- Frontend: React 18 + Vite + Tailwind CSS
- Backend: Node.js + Express + Prisma ORM
- Base de Datos: MySQL 8.0+
- Autenticación: JWT con refresh tokens

CARACTERÍSTICAS PRINCIPALES:
✓ 13 módulos completos y funcionales
✓ 4 roles de usuario (Admin, Analista, Cobrador, Consulta)
✓ Cálculo automático de cuotas (interés simple y compuesto)
✓ Sistema de mora configurable
✓ Múltiples cajas con arqueos
✓ 7 tipos de reportes (PDF + Excel)
✓ Notificaciones en tiempo real
✓ Sistema de configuración flexible
✓ 100% responsive y mobile-friendly

MÓDULOS INCLUIDOS:
1. Dashboard con métricas en tiempo real
2. Gestión de Clientes
3. Solicitudes de Cuenta
4. Aprobaciones
5. Cuentas y Calendarios
6. Pagos y Comprobantes
7. Morosidad y Cobranza
8. Múltiples Cajas
9. Notificaciones
10. Reportes Avanzados
11. Usuarios y Roles
12. Auditoría
13. Configuración del Sistema

REQUISITOS DEL SISTEMA:
- Node.js 18 o superior
- MySQL 8.0 o superior
- 1GB RAM mínimo
- 500MB espacio en disco
