# Finanzas Sanas Context

## Glossary

- **Cuenta bancaria de empresa**: cuenta administrada por la empresa para recibir cobros, conciliaciones o transferencias de clientes. Se configura en Pagos y Cobranza.
- **Cuenta de recepción**: destino bancario que pertenece a un cliente y se usa exclusivamente para recibir recursos. La CLABE se almacena cifrada y solo se presenta enmascarada.
- **Verificación de cuenta de recepción**: decisión administrativa que habilita o rechaza una cuenta de recepción para una transferencia.
- **Dispersión**: registro operativo de una entrega asociada a una cuenta financiada. Puede estar pendiente, confirmada o devuelta; registrar una dispersión no sustituye la confirmación de un proveedor SPEI.
